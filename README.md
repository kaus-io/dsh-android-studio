### 介绍

`DSH Android Studio` 是 DeepSeek Harness Web 的 Android 工作台与代码阅读器插件。在会话标题栏选择 App、变体和设备，完成 Debug 运行、APK / AAB 构建与签名，并在右侧栏查看任务输出；工作区源码预览支持语法高亮、折叠、大纲与查找。它不是 Android Studio IDE，也不是 Android App，不改写业务项目的 Gradle 配置。
